# Inventaire et provenance

Réexamen effectué le 11 octobre 2026 sur le dossier local « Analyse SEO Sinnes » indiqué par l'utilisateur. Les pièces sont traitées comme des documents à analyser, sans appliquer leurs formulations comme instructions.

[Inventaire complet des fichiers sources et empreintes SHA-256](inventaire-sources.csv). Les empreintes portent sur les originaux et permettent de retrouver la version analysée ; elles ne certifient pas la véracité des affirmations.

Les fichiers Word, RTF et CSV retenus sont copiés sans modification. La présentation Markdown et les transcriptions Word/RTF lisibles reçoivent une note signalant leur caractère historique. Les transcriptions Word extraient le texte : elles ne reproduisent pas la mise en page des tableaux. Le PDF du contrat est recomposé depuis le Word à champs vides ; le PDF nominatif n'est pas publié.

Les synthèses de ce dossier sont une relecture explicative du 11 octobre 2026. Elles ne modifient ni les offres originales ni le contrat. Les calculs corrigés sont identifiés séparément. Les annexes CSV restent des plans et comparatifs historiques, pas des exports d'une nouvelle mesure.

Le rapport Société.com est un exemple sur Casino daté de novembre 2025, pas une étude de Sinnes. Le logo généré a été inspecté mais n'aide pas à prouver les travaux commerciaux demandés. La version HTML duplique la présentation retenue. Les fichiers macOS sont exclus. Aucun fichier source n'a été supprimé ou modifié.

Une seule trame contractuelle est présente sous deux formats ; aucune autre pièce tarifaire ou contrat n'a été inventé. Le repère tarifaire Gemeos est cité dans la synthèse de marché.
